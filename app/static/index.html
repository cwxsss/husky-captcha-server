📡 核心 API 说明

POST /captcha Content-Type: application/json { "image": "data:image/png;base64,...", "type": "general" // 或 "numeric", "chinese", "math" } // 响应： { "ok": true, "data": { "value": "7a8b", "request_id": "req_123..." } }
